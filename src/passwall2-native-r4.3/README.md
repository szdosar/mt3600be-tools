# 原厂 MT3600BE 离线安装 Passwall2：native-r4.3

用途：网络代理、协议测试、连通性分析等科学研究。包含 Passwall2 26.10.20-r2、Xray 26.10.21-r2、sslocal、Haproxy、Sing-box 和匹配离线依赖，不附带节点或订阅。

仅适用于 GL-MT3600BE 指定官方 op25 测试版：4.9.1-op25 / OpenWrt 25.12.5 / r33051-f5dae5ece4 / Linux 6.12.94。先完成原厂初始化，从原厂高级设置安装并开启 LuCI。不要用于其他固件。

## 先恢复配置再安装

可以先恢复 OpenWrt 配置，再安装本包。两份插件配置 `/etc/config/passwall2` 和 `/etc/config/passwall2_server` 保留原内容、权限与主开关，支持 root:root 600/640/644/664。默认模板单独保留，不覆盖或自动合并已有配置。

如果旧事务路径仅剩空目录，安装器在取得原生互斥锁后检查目录属主、权限和完整树结构，将空目录原子改名到同一父目录下的 `empty-transaction-archive.随机串/transaction`，保留原目录后建立新事务。归档目标不覆盖、不复用，不以复制代替失败的原子改名。

**空文件也算实际记录。** 目录中只要存在文件、链接或特殊文件，就不能按空目录归档；正式事务缺少 phase、identity、SEAL 等记录时明确报错并保留现场。不要删记录、递归 chmod 或强装。执行过 firstboot 不能代替当前目录和包状态检查。

## 安装

将 `.run` 和对应 `.sha256` 文件放在路由器同一目录，在该目录运行：

```sh
sha256sum -c passwall2-high-native-r4.3.sha256 &&
sh ./passwall2-high-native-r4.3.run install --apply
```

安装保留 Passwall2 原生行为，可能写入 DHCP localuse、防火墙 include、uhttpd、ucitrack；恢复配置中的主开关若已开启，可能启动代理。安装期间不要同时保存配置。工具不重启路由器。

## 查询、重试与回滚

```sh
sh ./passwall2-high-native-r4.3.run status
sh ./passwall2-high-native-r4.3.run rollback --apply
```

回滚前从插件中正常关闭代理。只卸载本次新增包，恢复有记录的原生接入修改；已有包、用户插件配置和历史归档保留。配置冲突时停止，不用旧快照强盖新配置。

归档前中断：原事务仍在，可能多一个空的归档预留目录；重试不复用该目录。归档后、发布新事务前中断：原空目录已保留，重试确认归档仍无记录后继续建立新事务。若归档中出现文件或链接，重试拒绝，需单独检查。

普通 APK/UCI 安装或回滚中断，先查询，再重试同版命令；不能将回滚中的事务逆向用来安装。status、check、rollback 均不自动归档空事务，更不会因记录缺失报回滚成功。

## 旧版本

r4.2 保留对照。r4.2 仅留下空目录或未发布的准备目录时可换 r4.3 重试；已有正式 r4/r4.1/r4.2 事务不自动接管，仍使用原包处理。已验证完成回滚的 r3 接续规则保持不变。

本包复用未改动、已验签的 23 个 APK 与索引，不需要重新签 APK；更新的是外围事务处理和整个 run 的 SHA-256。项目签名不是厂商签名。
