# 原厂 MT3600BE 离线补装 Passwall2：native-r4.2

适用：[已测试的官方 op25 测试版](FIRMWARE.md)：4.9.1-op25 / OpenWrt 25.12.5 / Linux 6.12.94 / r33051-f5dae5ece4；不是其他官方固件的通用安装包。先从原厂高级设置安装并开启 LuCI。本包不是固件。

组合：Passwall2 26.10.20-r2 + Xray 26.10.21-r2，包含中文翻译、sslocal、Haproxy、Sing-box 和离线依赖。无需联网下载安装包。

## 修复了什么

恢复 OpenWrt 备份后，插件配置和标准防火墙接入还在、程序包没有了，现在可以保留配置补装，不必先逐个删除。安装器联合核对 APK 数据库、程序文件、版本和事务记录，不用“某个文件存在”判断已安装。

旧的非空有效插件配置、节点和权限保留；`passwall2` 与 `passwall2_server` 均接受 root:root 的 600、640、644、664 权限，不为安装而统一 chmod。标准 Passwall2 include、ucitrack 及启动链接纳入原始记录。未知脚本路径、异常链接、非法配置或已有其他版本仍会停止说明原因，不能强装。本包不接管其他来源已安装的 Passwall2。旧 r3 已核验完成回滚时，可建立独立的 r4.2 事务，旧记录原样保留；未完成、损坏或归属不明的旧事务仍拒绝。

## r4.2 新增修复与默认模板

r4.1 的权限白名单漏掉了包自身使用的 `664`，导致“先恢复配置、再安装”被误拒。本版补齐两份插件配置，并检查共享配置恢复场景；原生程序文件及安装脚本不变。

- 已有合法 `passwall2`、`passwall2_server`：使用已有配置，保持内容、归属和权限；没有文件时由 Passwall2 原生流程生成默认配置。
- 默认参考模板：从已签名 APK 提取，保存到 `/root/mt3600be-passwall2-run-v4/transaction/defaults/passwall2` 和同目录的 `passwall2_server`。主模板来自原包 `/usr/share/passwall2/0_default_config`，不包含设备私有数据。模板**不会自动应用或合并**。
- 不人工生成或覆盖 `.apk-new` / `-opkg` 文件；已有归属不明的 `.apk-new` 会停止核对。
- 重复安装不改已有配置或模板。回滚仅清理本事务未被修改的模板；修改了内容或权限的模板会保留，原始事务与用户配置仍保留。
- 配置出现链接、非 root 归属、全员可写、特殊权限或语法错误时仍拒绝，不通过强制 chmod、删除配置或覆盖默认值绕过检查。

r4.1 若仅因权限预检失败、尚未发布正式事务，可直接使用本版重试；旧预检目录保留。若已存在 r4/r4.1 正式事务（包括回滚历史），本版不直接接管，需继续使用原包处理并核对，不能删除历史强装。

## 从 r3 升级到 r4.2

你看到“已卸载本次新增包并恢复记录的原生接入修改”后，r3 留下事务记录是正常行为。旧 r4 错把这份历史当成未卸载；请换用本版，**不要删除 `/root/mt3600be-passwall2-run-v3`，也不用删插件配置或防火墙规则**。

r4.2 会核验 r3 版本归属、原始记录完整性、回滚完成状态、新增包确已移除，以及共享配置的恢复结果。核验成功后才建立自己的事务。r4.2 已开始安装后，查询、重试和回滚均用 r4.2，不再使用 r3 管理新安装。

若 r3 回滚后又改过 DHCP、防火墙或 LuCI 等共享配置，本版会提示具体冲突并停止，不拿旧备份覆盖新设置。请保留现场核对。已发布的 r4/r4.1 事务不属于本次接续范围，不要直接拿 r4.2 覆盖。

## 安装

1. 将 `passwall2-high-native-r4.2.run` 与 `passwall2-high-native-r4.2.sha256` 一起上传到路由器新建的空目录，例如 `/tmp/pw-r4.2`，不要覆盖 r3 文件。
2. 登录路由器 SSH，执行：

```sh
cd /tmp/pw-r4.2 &&
sha256sum -c passwall2-high-native-r4.2.sha256 &&
sh ./passwall2-high-native-r4.2.run install --apply
```

校验或安装失败时停止，保留输出，不删事务目录、不加 force 参数。安装期间不要同时改设置、操作开关或安装其他软件。

安装使用原生脚本：新配置默认关闭，已有配置及原先的主开关保留。**如果旧主开关为开启，原生安装流程可能直接启动代理。** 安装完成后到 LuCI 核对节点、主开关并保存应用。本包不主动重启路由器。

如果此前按旧包提示把配置移到 `/tmp/release/passwall2`、`/tmp/release/passwall2_server`，它们仍是你的原文件；不要删除、不要重启（重启会清空 `/tmp`）。确认来源及目标不存在后，可先恢复到各自的 `/etc/config/` 路径，再运行 r4.2。目标已存在时先比较确认，不能覆盖新的配置。r4.2 不会自动搜寻或接管 `/tmp` 中的配置。

## 查询和失败重试

在同一个目录：

```sh
sh ./passwall2-high-native-r4.2.run status
```

安装失败或断线后，先查状态，再运行同一条安装命令。已完成的同版本事务不会重装。配置在中断期间被修改时，安装器会拒绝覆盖，保留现场。旧 r3 仅预检失败留下的目录不会阻止安装。r3 正式事务须先用原 r3 执行 rollback --apply，成功后使用本版安装；无需删除 r3 事务目录。已提示回滚完成的，不需要为了这次更新再回滚一遍。

## 回滚

```sh
sh ./passwall2-high-native-r4.2.run rollback --apply
```

先在 LuCI 正常关闭正在运行的代理。回滚仅删除本次新增包，保留安装前已有的同版本依赖和用户插件配置，并恢复本次原生接入修改及原有启动链接。安装后又修改的共享防火墙等配置不会被旧快照覆盖，遇到冲突会停止供核对。

中断后可重复运行同一条回滚命令。回滚后的事务不反向复用，也不要删除原始记录强行重装。模板清理中断可重试；模板归属记录损坏或缺失时拒绝卸载，防止误删。已被用户修改的模板保留在原目录。
