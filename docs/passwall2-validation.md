## 配置范围

逐一检查 23 个 APK 的文件清单，保留两份用户插件配置：`/etc/config/passwall2`、`/etc/config/passwall2_server`。主配置由原生安装脚本生成；服务端配置由 APK 提供且原始权限正是 664。允许 root:root 600/640/644/664，原内容、权限和主开关保留。不是对所有 `/etc` 文件放行；init、hotplug、uci-defaults、modules.d 是程序文件，仍检查冲突。

默认模板取自签名 APK，独立保存为事务目录中的 `defaults/passwall2` 和 `defaults/passwall2_server`，不覆盖或自动合并现有配置。共享 DHCP、防火墙、uhttpd、ucitrack、LuCI 配置沿用原生安装行为及原有回滚保护，补测 664 权限恢复。

## 中断与旧事务

两份默认模板和归属清单在事务原子发布前准备完成。未发布的旧准备目录保留，不重用。重复安装不改模板；回滚只删除内容和权限均未改变的本事务模板，用户编辑保留。清理中断后可重复回滚；模板清理期间发生编辑则先拒绝，重试时保留编辑。

仍使用原有跨版本互斥锁。本版允许已核验完成回滚的 r3 接续；不强行接管已发布的 r4/r4.1 正式事务。旧 r4.1 仅权限预检失败时可以换本版重试。不要删除历史记录绕过保护。

以上为断网隔离文件系统、真实 APK/UCI 与故障注入测试；服务及内核接口是测试替身，不代表真机代理流量或实际断电验收。本轮未连接、安装或修改 8.1，也未修改 dt 路由。测试夹具中的旧 SDK 头文件路径和事务封存规则已修正，最终全套回归从头运行通过。

保留 Passwall2 原生安装行为，可能修改 DHCP localuse、防火墙 include、uhttpd、ucitrack；恢复的主开关若开启，可能启动代理。安装和回滚期间不要同时修改设置。不额外调整原厂上游 DNS、VPN、无线或区域码。任意不遵守工具锁的 root 进程不属于全局隔离保证。步骤见小白安装说明.md。
