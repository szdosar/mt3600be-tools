# native-r4.3 验证范围

在 r4.2 基础上增加持锁空事务归档，不改变 Passwall2 原生文件、依赖、签名、安装钩子或现有配置保留规则。

发布门禁要求：113 项全套隔离回归通过，其中新增 14 项空事务/恢复配置/并发/中断异常测试；真实 ARM APK/UCI/helper 完成空事务归档、保留 664 配置安装/重复/回滚；真实 ARM 旧 r3 接续；23 APK 与索引验签；run 包完整性及损坏、并发解包和中断测试。

新增覆盖：仅空目录、零字节记录、嵌套记录、符号链接、FIFO、目录权限异常、归档前/后中断、安装与回滚并发、检查期间新增记录、归档目标竞争、改名失败拒绝复制、只读查询/检查与回滚不归档、归档后 APK 中断、正式事务丢失记录时拒绝。

归档使用原生安装互斥锁、目录 FD 身份检查和现有 fs-safe 的 renameat2(RENAME_NOREPLACE) 原子改名及父目录 fsync。保留旧目录，不删除配置和原始备份。不承诺隔离任意不遵守互斥锁的 root 程序；检测到此类变化时保留现场并拒绝后续新建事务。

所有离线测试使用合成配置，无用户节点或密码。APK、索引、默认模板、辅助程序字节与 r4.2 一致，只有控制器变化。没有重新读取签名私钥，也不将设备事务和备份写入安装包。

8.1 本次仅完成独立的空事务归档，配置内容前后相同，未运行新版安装/回滚或重启。因此不能将本机测试写成 r4.3 真机安装通过。最终结果见 [验证结果](../tests/passwall2-r4.3-validation.json)。
