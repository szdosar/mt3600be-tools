# 在线入口 online-v1.2

适用范围保持不变：GL-MT3600BE，指定官方 op25 测试版 4.9.1-op25 / OpenWrt 25.12.5 / r33051-f5dae5ece4 / Linux 6.12.94。

使用 [首页最新整段命令](../README.md#小白怎么用)，选择工具和安装/查询/回滚，再按提示确认。旧命令固定在旧版入口，不会自行更新；请重新复制新命令。无需安装 stat，无需删除任何旧事务或配置。

## 修复及保护

- 有 stat 时继续使用；没有时使用固件自带 ucode 的 fs.stat/fs.lstat。不下载额外执行器、不修改软件源。
- 保留权限、属主、类型、大小、SHA-256、稳定锁文件及打开 FD 身份检查。普通路径不跟随符号链接；仅打开 FD 的身份查询显式跟随 /proc 链接。
- 元数据 API 报错、缺少模块、返回空值均拒绝；读取锁两侧身份均检查返回码，不能将两个失败的空结果误判为一致。
- 固定版本/摘要、独立执行副本、双终端互斥、确认流程和组件事务不变。EEE 与 Passwall2 run 包及签名不变。
- 原生 Passwall2 接入行为保持不变，不能把本次兼容修复理解成“安装不会修改 DHCP/防火墙等接入”。详见首页改动范围。

## 重试与回滚

下载失败可重跑最新命令；校验失败或旧缓存损坏时停止，不覆盖旧缓存，不执行旧文件。双终端请等待正在执行的任务完成。普通中断会清理本次临时文件；子工具运行时保留锁等待其结束。强杀/断电可能留下临时残片；重试使用新文件，保留未知残片和组件事务，不强制清理。

SSH 断线先查询状态，再按组件说明重试同版。已经缓存的 run 可断网查询/回滚，见 [离线命令](OFFLINE.md)。不要删除锁、原始快照或事务来强装。

## 测试边界

目标环境测试使用公开原厂镜像中的真实 ARM BusyBox、ucode、fs.so，通过 QEMU 用户态和 bwrap 断网沙箱运行。uname、下载及组件动作是合成替身，不访问路由器，不操作 PHY，不安装或卸载真实插件。不能视为真机 EEE/代理/重启验收。

旧入口 online-v1.1 及其 Release 保留供对照，不替换既有附件。
