# MT3600BE WAN EEE 工具 v1.2-r4

仅适用于原厂 4.9.1-op25 / OpenWrt 25.12.5 / Linux 6.12.94，WAN eth0 RTL8221B。用于规避1G WAN链路下与EEE相关的丢包。不刷机、不自动重启，不修改DNS、VPN、无线或插件配置。

1. 先连接WAN上游，电脑通过LAN管理路由器；备份现有配置。
2. 上传run及sha256文件，在同目录执行：

```sh
sha256sum -c mt3600be-eee-tool-v1.2-r4.sha256 && sh ./mt3600be-eee-tool-v1.2-r4.run
```

3. 先查看状态，再选安装；输入YES才执行。安装可能短暂重新协商WAN。

## 恢复配置后安装

- 文件与事务均无：新安装先只读检查。timer=0时拒绝写入且不创建事务；接好WAN再查询。已观察到0自然变成1000，但不是所有情况下都保证会变化，不要强改计时器。
- 旧事务不完整：不会覆盖。无补丁文件或启动链接残留时，可选择“归档不完整事务”，确认后保留原记录，再重新安装。新安装保存当前状态作为**新的**回滚基线。
- 完整且校验通过：保留已有安装及快照，不重复安装、不偷偷启用已回滚的服务。支持查询及回滚既有v1.1/v1.2-r2/r3记录；不会自动升级旧安装文件。
- 部分文件、损坏记录、版本不支持：停止并保留现场，不删除备份强装。

EEE disabled、存在目录或installed标记均不能单独证明补丁有效。状态需结合文件/快照校验、运行标记、服务和硬件字段；正常启用应为active=0、TX LPI=0、本机advertised=0、PHY宣告=0。

## 回滚和中断

菜单提供回滚、重新启用、只读状态。回滚恢复当前正式事务的基线，保留工具及所有快照；不会使用归档的timer=0记录。回滚后可能再次丢包。

断线后先重新查询，再重试同一操作；双终端忙锁会拒绝。不要删除锁、事务或原始快照。归档后旧文件始终保留，新基线与旧快照不能混用。
